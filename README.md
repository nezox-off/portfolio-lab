# Портфоліо Максима Полякова (React + Vite)

Сайт з 4 сторінок: Головна, Про мене, Проєкти, Контакти. Українська мова.

## Запуск

    npm install
    npm run dev

Збірка для публікації: `npm run build` (папка `dist`).

## Структура

- `src/data.js` — усі тексти, навички, проєкти та контакти (редагувати тут)
- `src/pages/` — сторінки
- `src/components/` — Header, Footer, Card
- `src/styles.css` — стилі (світла й темна теми)

Контакти в `src/data.js` — заглушки (`your@email.com` тощо), замініть на свої.
